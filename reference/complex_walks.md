# Count Walks in complex signed network

Count Walks in complex signed network

## Usage

``` r
complex_walks(g, attr, k)
```

## Arguments

- g:

  igraph object.

- attr:

  edge attribute that encodes positive ("P"), negative ("N") and
  ambivalent ("A") ties.

- k:

  integer. length of walks

## Value

complex matrix

## Author

David Schoch

## Examples

g <- as_complex_edges(g, attr = "type")
complex_walks(g, attr = "type", k = 3)
