# Signed network of New Guinean highland tribes

Signed social network of tribes of the Gahuku–Gama alliance structure of
the Eastern Central Highlands of New Guinea, from Kenneth Read. The
network contains sixteen tribes connected by friendship ("rova") and
enmity ("hina").

## Usage

``` r
tribes
```

## Format

An igraph object

## Source

http://vlado.fmf.uni-lj.si/pub/networks/data/ucinet/gama.dat

## References

Read, K. E. (1954) Cultures of the central highlands, New Guinea.
*Southwestern Journal of Anthropology*, 1–43.
